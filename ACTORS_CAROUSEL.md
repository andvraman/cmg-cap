# CapBuild Actors & User Stories Carousel

An interactive visualization of the 10 key actors in the CapBuild system, each with their 9 most consequential user stories.

## Overview

This carousel provides a quick reference guide to:
- **10 system actors** with distinct roles and responsibilities
- **9 user stories per actor** describing their primary workflows
- **Color-coded identification** for visual differentiation
- **Interactive story exploration** with smooth scrolling

## Features

- **Interactive carousel** — Click any actor to view their user stories
- **Smooth scrolling** — Auto-scroll highlights the story band is interactive
- **Color-coded borders** — The selected actor's color frames their stories
- **Clickable stories** — Select individual stories to highlight them in navy
- **Responsive design** — Works on all screen sizes
- **Minimalist UI** — Clean, distraction-free presentation

## Usage

### Viewing Online
Visit the interactive artifact: [CapBuild Actors & User Stories](https://claude.ai/artifact/5tiG8YPzAdsJEaCy46bwXn)

### Local File
1. Open `actors-carousel.html` in your browser
2. Click any actor card to view their user stories
3. Click any story to highlight it
